# نظام صيدلية الأم والطفل

منصة تشغيل عربية لإدارة صيدلية بيع بالتجزئة، سريعة وواضحة، مع توسع مدروس للعيادة والأطباء الزائرين والوصفات الإلكترونية مستقبلًا.

## الحالة الحالية

المشروع في **Phase 0 — Product Discovery & Vision**. لم يبدأ تطوير التطبيق لأن الـMaster Prompt يمنع البرمجة قبل اعتماد الاكتشاف والمتطلبات والعمليات والنموذج والواجهة والمعمارية والأمن.

## نطاق الإصدار الأولي

- كتالوج الأدوية ووحدات البيع والباركود الداخلي والخارجي.
- استيراد من Excel وPDF والصور أو الإدخال اليدوي.
- استخراج أولي وشاشة مراجعة بشرية إلزامية قبل الحفظ.
- مخزون حسب الدفعة والصلاحية وتطبيق FEFO.
- مشتريات وموردون وعملات متعددة واستلام جزئي.
- نقطة بيع تعمل بالباركود أو بالبحث والاختصارات بدونه.
- ورديات وصندوق ومبيعات ومرتجعات وتدقيق كامل.
- مرضى ووصفات ورقية، ثم عيادة وأطباء ووصفات إلكترونية مستقبلًا.

## بنية المشروع

- `docs/phase-0/`: الرؤية والاكتشاف.

- `docs/architecture/`: مخطط العمارة الأولي والحدود في MVP.

## حالة العمل الحالية

### مكتمل

- توثيق Project Discovery & Vision
- تسجيل الافتراضات والقرارات والمخاطر والتبعيات
- إعداد سيناريوهات الأعمال الذهبية الأساسية
- إعداد مخطط العمارة الأولي ومحددات MVP
- إعداد خطة UX الأولية

### قيد التنفيذ/مفتوح

- اعتماد المالك على قرارات Gate 0
- جرد الأجهزة والطابعات والشبكة والكهرباء
- تحديد الصور الثمانية وملفات الموردين والهوية البصرية
- تأكيد العملات والضرائب وسياسات المرتجعات والأدوية المقيدة
- اختيار التقنية النهائية بعد Decision Matrix

### التالي

- إغلاق Gate 0 وموافقة المالك
- بدء Phase 1: مقابلات التشغيل والبيانات والأجهزة
- بناء BRD/SRS المتكامل من القواعد المعتمدة
- إعداد UX/Interface وWireframes لاحقًا

## قواعد ملزمة

1. كل حقل يحمل اسمًا عربيًا واضحًا يصف وظيفته.
2. قارئ الباركود اختياري والبحث اليدوي بديل كامل.
3. الاستيراد لا يؤثر على المخزون قبل المراجعة والاعتماد.
4. المعاملات المكتملة تُعكس أو تُرجع ولا تُعدّل بصمت.
5. لا يباع Batch منتهي الصلاحية ويطبق FEFO.
6. الوصفة والصرف والبيع والدفع كيانات منفصلة.
7. الذكاء الاصطناعي لا يتخذ قرارًا علاجيًا.
