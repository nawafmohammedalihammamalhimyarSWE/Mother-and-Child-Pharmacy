# Phase 0 — Product Discovery & Vision

**الحالة:** مسودة تحتاج اعتماد مالك المشروع  
**التاريخ:** 2026-08-17  
**المنتج:** نظام صيدلية الأم والطفل  
**Gate 0:** غير معتمد

## A — فهم المشروع

المطلوب منصة تشغيل يومية لصيدلية بيع بالتجزئة في اليمن، عربية وواضحة وسريعة، تتحمل ضعف الإنترنت وتقلب سعر الصرف، وتدير الدواء كمنتج حساس له دفعة وصلاحية ووحدة بيع وظروف تخزين.

يدخل كتالوج الأدوية من Excel أو PDF أو صور مستندات الموردين أو يدويًا. تمر كل دفعة استيراد بالاستخراج والتوحيد والفحص والتعديل والمعاينة والاعتماد البشري. قارئ الباركود أداة تسريع اختيارية، والبحث العربي والإنجليزي بديل كامل.

المشروع يبدأ بالصيدلية. توسعة العيادة مستقبلية وتشمل أطباء يعملون لمرة واحدة أو أسبوعيًا أو شهريًا أو وفق جدول مخصص. يبدأ التكامل الطبي بتسجيل بسيط للمريض وأرشفة وصفة ورقية، ثم وصفة إلكترونية مستقبلًا. لا ينبغي أن تعقّد ميزات المستقبل تشغيل الصيدلية الحالي.

النظام الحالي المبني على ERPNext مرجع وظيفي تقريبي بنسبة 50% حسب تقييم المالك، وليس قاعدة تُنسخ حرفيًا. نستفيد من مفاهيم المحاسبة والمخزون ونعالج تعقيد الواجهة وضعف الاستيراد والوصفة والوردية.

## B — رؤية المنتج

> تمكين صيدلية الأم والطفل من بيع الدواء وشرائه وتتبع مخزونه ودفعاته وصلاحيته ووردياته وأمواله بسرعة وأمان حتى عند ضعف الاتصال، مع تأسيس جسر تدريجي للمرضى والأطباء والوصفات.

### أهداف أولية

- بيع عادي بالباركود خلال 30 ثانية بعد التدريب.
- البيع بالبحث دون باركود دون فقد وظيفة أساسية.
- منع بيع أي دفعة منتهية الصلاحية.
- تتبع كل حركة كمية ومال ومستخدم ومرجع ووقت.
- مراجعة بيانات أي ملف مستورد قبل تأثيره على المخزون.
- دعم نسخة احتياطية قابلة للاختبار والاستعادة.

### Non-Goals للإصدار الأول

- تشخيص أو علاج آلي.
- نظام عيادة كامل قبل استقرار الصيدلية.
- تأمين أو ربط حكومي قبل بحث واعتماد رسمي.
- Microservices معقدة دون حاجة مثبتة.

## D — خريطة الوحدات

النواة: الهوية والصلاحيات، الفروع والمخازن، كتالوج الأدوية، الاستيراد والمراجعة، الموردون والمشتريات، الدفعات والمخزون، التسعير، POS، المبيعات والمدفوعات، المرتجعات، الورديات والصندوق، المحاسبة، التقارير، التدقيق والنسخ الاحتياطي.

الجسر الطبي: سجل مريض مبسط وأرشفة وصفة ورقية. المستقبل: الأطباء والتعاقدات والجدولة والزيارات والوصفات الإلكترونية.

## E — لجنة العميل الرقمية

المالك، المدير، صيدلي الصباح، صيدلي المساء، الكاشير، مسؤول المخزون، مسؤول المشتريات، المحاسب، المدقق، الطبيب الزائر، موظف الاستقبال والمريض. إجابات اللجنة افتراضات محاكاة وليست بديلًا عن اعتماد المالك أو البحث القانوني.

## F — أسئلة الاكتشاف

1. ما مدينة التشغيل وعدد الفروع المخطط؟
2. كم مستخدمًا ووردية وفاتورة يوميًا؟
3. ما العملات المستخدمة في الشراء والبيع؟
4. هل توجد معالجة منفصلة للريال القديم والجديد؟
5. ما الضرائب والإعفاءات الفعلية؟
6. ما سياسة الأدوية المقيدة والمرتجعات؟
7. ما وحدات البيع المسموحة: علبة، شريط، حبة؟
8. ما الحواسيب والطابعات وقارئات الباركود المتوفرة؟
9. هل يوجد خادم محلي؟ وما واقع الكهرباء والإنترنت؟
10. ما نوع ملفات الموردين الأكثر شيوعًا؟
11. هل الصور الثماني مخزون افتتاحي أم فواتير أم قوائم أسعار؟
12. من يعتمد OCR ومن يحق له تعديل التكلفة والسعر؟
13. هل توجد قاعدة أو Excel سابقة؟
14. كيف يحتسب الربح عند تغير سعر الصرف؟
15. ما طرق الدفع والديون المسموحة؟
16. ما مدة المرتجع وشروط إعادة الدواء للمخزون؟
17. هل المرضى ضمن MVP أم بعد استقرار الصيدلية؟
18. ما اسم العيادة وموقعها المتوقع؟
19. كيف يحاسب الطبيب الزائر: زيارة أو نسبة أو يوم أو شهر؟
20. هل يحتاج الطبيب دخولًا من خارج الشبكة؟

## G — ورشة العميل الافتراضي

| الموضوع | القلق | النتيجة الأولية |
|---|---|---|
| البيع | جهاز الباركود قد يتعطل | الباركود اختياري |
| الاستيراد | OCR يخطئ في الاسم والسعر | مراجعة بشرية إلزامية |
| المخزون | الإجمالي يخفي الدفعات | Batch وStock Ledger إلزاميان |
| الصلاحية | اختيار دفعة خاطئة | FEFO ومنع المنتهي |
| المرتجع | قد يحدث في وردية أخرى | Return مستقل مرتبط بالأصل |
| العملة | الربح يتغير بسعر الصرف | حفظ سعر الصرف مع المعاملة |
| الأطباء | تكرارات تعاقد مختلفة | Schedule مرن |
| الوصفة | الطبيب يستخدم الورق الآن | Paper-first ثم Electronic Rx |
| الحقول | ترجمة حرفية غامضة | اسم واضح يصف العمل |

## H — تعارضات المتطلبات

1. Offline 100% مقابل تعدد الأجهزة: قاعدة محلية بكل جهاز تحتاج مزامنة؛ خادم محلي قد يكون أبسط.
2. السرعة مقابل الاعتماد: تستخدم حدود صلاحيات قابلة للتهيئة بدل موافقة المدير على كل شيء.
3. OCR آلي مقابل الدقة: الاستخراج آلي والحفظ بشري الاعتماد.
4. البيع السريع مقابل السلامة: المنع للحالات الحرجة والتنبيه المتوازن للبقية.
5. العيادة المستقبلية مقابل MVP: نجهز الحدود دون بناء EMR كامل الآن.
6. الحذف مقابل التدقيق: الحركات تُلغى أو تُعكس ولا تحذف.

## N — فجوات الاكتشاف

- المدينة والفروع والمستخدمون والحجم غير معروفة.
- القوانين والضرائب والأدوية المقيدة والاحتفاظ غير محسومة.
- نوع مستندات المورد الحالية غير مؤكد.
- لا يوجد شعار معتمد أو صور للصيدلية أو عبوات الأدوية.
- لا يوجد Excel/PDF أصلي أو مخزون افتتاحي معتمد.
- الأجهزة والطابعات والشبكة والكهرباء غير مجرودة.
- سياسة المرتجع والخصم والديون وسعر الصرف غير معتمدة.
- توقيت المرضى والعيادة والوصفة الإلكترونية غير معتمد.

## P — خارطة الطريق

1. Gate 0: اعتماد الرؤية والنطاق.
2. Phase 1: مقابلات وجرد الأجهزة والبيانات والعمليات.
3. Phase 2: بحث السوق والمعايير والقوانين من مصادر رسمية.
4. Phase 3–4: AS-IS/TO-BE وBRD/SRS.
5. Phase 5: Domain Model وState Machines وERD.
6. Phase 6–7: UX والهوية والWireframes واختبارها.
7. Phase 8–10: المعمارية والتقنية والأمن.
8. Phase 11–12: مهام ذرية وتبعيات وإصدارات.
9. Phase 13+: Vertical Slices واختبارات مستمرة.
10. الإطلاق: Foundations ثم Catalog/Import ثم Purchase/Inventory ثم POS/Shift/Return.
11. الجسر الطبي: Patient Lite ثم Paper Rx Archive.
12. المستقبل: Visiting Doctors ثم Clinic Scheduling ثم Electronic Rx.

## Q — معايير خروج Phase 0

- اعتماد اسم المنتج والرؤية والنطاق وNon-Goals.
- إجابة قرارات المالك عالية الأولوية.
- تأكيد معنى مستندات المورد الحالية.
- تحديد الموقع والفروع والمستخدمين والورديات والعملات.
- الاتفاق أن العيادة المستقبلية لا تؤخر MVP.
- قبول الوحدات والمبدأين: الباركود اختياري، ومراجعة الاستيراد إلزامية.
- قبول عدم الحذف الصامت وسجل التدقيق.
- تحويل Gate 0 إلى Approved.

## الحالة

- **اكتمل:** قراءة Master Prompt، جرد الوثائق، تصنيف الصور، الرؤية والوحدات والسجلات والسيناريوهات الأولية.
- **لم يكتمل:** اعتماد المالك، بحث القوانين، مقابلات التشغيل، جرد الأجهزة، تحليل البيانات، اختيار التقنية.
- **المخاطر الأعلى:** OCR، فقد البيانات، تضارب المخزون، سعر الصرف، الصلاحية، توسع العيادة مبكرًا.
- **التالي:** إجابات المالك، جرد الأجهزة، تعريف الصور، توفير الشعار والصور والملفات الأصلية.
